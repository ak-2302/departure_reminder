# 料金と外部サービス設定

## 結論

- Google Calendar APIの標準利用は追加料金なし。ただし、Googleのクォータと将来の課金条件に従う。
- Google Routes APIは従量課金のGoogle Maps Platformサービスで、利用にはCloud Billingの有効化とAPIキーまたはOAuthトークンが必要。
- 料金はAPIの種類、SKU、無料利用枠、リクエスト数によって変わるため、固定額としてアプリへ記載しない。

## 開発者が設定するもの

1. Google Cloudプロジェクトを作成する。
2. Google Calendar APIとRoutes APIを有効化する。
3. OAuth同意画面と`calendar.events.readonly`スコープを設定する。
4. Android用OAuthクライアントIDを作成し、次のHTTPSリダイレクトURIを登録する。

```text
https://ak-2302.github.io/departure_reminder/oauth2redirect
```

5. Routes APIキーにアプリ制限とAPI制限を設定する。
6. Routes APIの日次クォータとCloud Billingの予算アラートを設定する。
7. 実行前に無料利用枠・単価・請求条件を公式料金表で確認する。

## 実装上のコスト対策

- 経路結果を10分間メモリキャッシュする。
- 同一条件の同時リクエストを共有する。
- アプリ復帰・ネットワーク復旧時だけカレンダーを同期する。
- バックグラウンド処理ではRoutes APIを再取得せず、最後に成功した移動時間を使う。
- Calendar APIとRoutes APIの再試行対象を制限し、無限再試行しない。
- Cloud Consoleで日次クォータと予算アラートを設定し、想定外の利用を検知する。
